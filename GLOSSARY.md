# Glosariusz P₀ (PL → EN)

Konwencja drzewa (tura 12): wiedza projektowa rośnie jak drzewo — korzenie → pień → gałęzie. Soki w górę niosą hipotezy i pytania; soki w dół — wyniki i erraty.

| Termin | EN | Znaczenie |
|---|---|---|
| pień | trunk | rdzeń algebraiczny projektu; jedyne źródło prawdy (SSOT) |
| słoje | (growth) rings | warstwy pnia; **każdy słoje = jedna niezależna replikacja (Z1)**; ✅ wymaga ≥2 słojów |
| sęki | knots | wyniki wycofane lub obalone; trwałe, indeksowane w pniu, nigdy nie usuwane (Z0) |
| korzenie | roots | filary: intuicje i pytania; hipotezy wypływają nimi ku górze |
| gałęzie | branches | operacjonalizacje i zastosowania (np. szachy, model AI) |
| miazga | cambium | laboratorium dowodu i metody — tam powstają nowe słoje |
| szopa | shed | (odroczona) przyszła archiwizacja implementacji z metadanymi; „kod nie rośnie na drzewie" (Z3) |
| tura | turn | jednostka pracy warsztatu (jedna sesja zespołu) |
| errata | errata | format: dokument → § → jest → powinno być → uzasadnienie → status weryfikacji |
| koncesja | concession | jawne przyznanie własnego błędu przy eracie (wzorzec kultury Z0) |
| bramka sanity | sanity gate | tablica kontrolna otwierająca replikację: porównanie z tabelą referencyjną **przed** rachunkami własnymi |
| bramka | gate | 8 z 20 ścian ikosaedru odpowiadających wierzchołkom jednego z 5 sześcianów wpisanych w dwunastościan |
| wachlarz | fan | 4 z 5 ścian wokół osi ikosaedru (konstrukcja w dokumentach Stalk) |
| P₀ | Point Zero | nazwany punkt odniesienia konstrukcji; „punkt zerowy nie jest pustką — jest zgodą wszystkich napięć na wspólne istnienie" |
| dokument warsztatowy | working document | żywy dokument rejestru prowadzony w warsztacie (raport replikacji, lattice, dziennik) |
| SSOT | single source of truth | pień; dokument FOUNDATION jest podzbiorem-bramką pnia |

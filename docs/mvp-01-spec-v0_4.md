## §1. MVP-01a (etap złącza) — hipoteza i pre-registracja kryteriów

**H_a (przeformułowana w rundzie 11i z ataku Claude'a; mierzy dokładnie to, co test liczy):** efekt obustronnego odcięcia f0 w miarze V_f = |U_f| jest **atypowo mały** względem pełnego rozkładu |U_z| w populacji 361 par odcięć — tj. **kanał ścianowy interfejsu jest marginalny**. Hipoteza dotyczy wyłącznie wkładu ścianowego; kanału wierzchołkowego etap a NIE testuje (§0L — fakt konstrukcyjny). Teza o nośniku fizycznym transportu → MVP-02 (D1). Falsyfikowalność: kategoria „obalenie" (1.2).

**1.1 Miara (jedna, zero swobód):** U_f = 1 − ρ_cut/ρ_AB; **V_f = |U_f| = 0.008174637** (publiczna, deterministyczna funkcja zamrożonych fingerprintów §0: ρ_AB = 0.554641699189, ρ_cut = 0.550107704834; znak U_f dodatni — odcięcie F₀ zmniejsza lukę subdominanty). **1.5 Asercje exact per realizacja (warstwa I — certyfikaty; fail-fast przed klasyfikacją, identyfikator realizacji w raporcie):**
- **(a) Rząd:** Bareiss z pełnym pivotowaniem na M := N_z − 256³⁸·I: rząd(M) = 22; certyfikat = lista pivotów (odtwarzalna). Reguła pivotowania deterministyczna (runda 11l, A5): w kroku k wybierany jest pivot o największej wartości bezwzględnej w aktywnej podmacierzy; przy remisie wartości bezwzględnej — para (wiersz, kolumna) najmniejsza leksykograficznie w bieżącej permutacji; permutacje wierszy i kolumn zapisywane w certyfikacie; pivot = 0 ⇒ rząd dekretowany = liczba wykonanych kroków, zapis świadków minorów.
- **(b) Prostota algebraiczna PF:** p_Nz(256³⁸) = 0 oraz (λ−256³⁸)² ∤ p_Nz (podzielenie syntetyczne BigInt, reszta ≠ 0). Uzasadnienie strukturalne (uwaga Asteriona 11j, przyjęta): R_z = N_z/256³⁸ jest nieujemną macierzą stochastyczną WIERSZOWO (nieujemność i sumy wierszy = 256³⁸ dokładnie, konstrukcyjnie z definicji S_A, S_B; „konwencja kolumnowa" §0 oznacza kolejność składania operatorów, nie stochastyczność kolumnową — errata 11k po ataku Claude'a), zatem potęgi R_z są ograniczone (||R_z^k||_∞ = 1), co wyklucza nietrywialny blok Jordana przy |λ| = 1; certyfikat liczbowy (b) wymagany mimo dowodu.
- **(c) ρ_z < 256³⁸ (certyfikat Schur–Cohn, exact, konwencja jawna):** q(μ) := p_Nz(256³⁸·μ)/256^(38·23) — wielomian moniczny stopnia 23 o współczynnikach wymiernych dyadycznych a_m(R_z)/256^(38·(23−m)); tożsamość q(μ) = det(μ·I − R_z) jest definicją pierwotną i zapis „a_m(R_z)" czyta się WYŁĄCZNIE przez nią (bez dodatkowego skalowania współczynników; runda 11l, A1/C2); przy p_Nz(λ) = Σ_{m=0}^{23} a_m(N_z)·λ^m współczynnik q przy μ^m równa się a_m(N_z)/256^(38·(23−m)) (errata 11k po ataku Claude'a: NIE całkowitych — implementacja zakładająca całkowitość ucina dzielenia i unieważnia certyfikat); q(1) = 0 (b); deflacja syntetyczna q(μ) = (μ−1)·r(μ), r moniczny stopnia 22, wymierny dyadyczny. Rekurencja Schura: P_22 := r; dla k = 22, …, 1: γ_k := P_k(0) (wyraz wolny); warunek certyfikatu: |γ_k| < 1 ∀k; redukcja P_{k−1}(z) := [P_k(z) − γ_k·P_k*(z)] / (z·(1 − γ_k²)), gdzie P_k*(z) = z^k·P_k(1/z); wszystkie operacje exact na ułamkach (licznik/mianownik BigInt); stopień 0 zamyka rekurencję. Tw. Schur–Cohna: r stabilny wewnętrznie (wszystkie pierwiastki |μ| < 1) ⇔ warunek spełniony ⇔ ρ_z < 256³⁸. Dowolne |γ_k| ≥ 1 ⇒ asercja fail (1.7).
- **(d) Domknięcia exact:** tr(N_z^k) z potęg macierzowych BigInt, k = 1, …, 4; zgodność z p_Nz (tożsamości Newtona); niezgodność ⇒ fail. Kontrola anty-cyrkularna (lekcja E11; errata 11k po ataku Claude'a): dla pre-registrowanych stałych λ₀ ∈ {256³⁸, 256³⁸+1, 2·256³⁸} porównanie p_Nz(λ₀) z det(λ₀·I − N_z) policzonym Bareissem — niezależna droga rachunkowa od Leverriera; niezgodność ⇒ fail. Rola kontroli przy λ₀ = 256³⁸ (runda 11l, C3): pokrywa się wartością z (b) — jej funkcją jest spójność metod Bareissa i Leverriera, nie niezależny fakt; λ₀ = 256³⁸+1 i 2·256³⁸ pozostają niezależne.
- **(e) Degeneracja:** p_Nz(i,j) = p_Nz(j,i) współczynnik po współczynniku, wykonywana dla par i < j; niezgodność ⇒ fail. ρ_z wyznaczane jednokrotnie na klasie nieuporządkowanej {i,j} i przypisywane obu członkom pary uporządkowanej (runda 11l, C4 — eliminuje pseudoremisy numeryczne wewnątrz klasy; remisy między klasami rozstrzyga klucz (V_z, i, j) — D3).

**1.6 Numeryka (warstwa II) i eskalacja (D6; uwaga Asteriona 11j przyjęta):** DK wykonywany na przeskalowanym q(μ) (1.5c; pierwiastki μ, λ = 256³⁸·μ; zakres double bez overflow); inicjalizacja deterministyczna: μ̂_k = exp(2πi(k+1/2)/23), k = 0..22, bez losowości; stop: max|Δμ̂| < 2⁻⁵² lub 200 iteracji; kompletność: 23 pierwiastki licząc krotności; residuum |q(μ̂)| publikowane per realizacja. **Δ_num(μ̂) = (Σ_m |d_m|·|μ̂|^m)·2⁻⁵³/|q′(μ̂)|** (d_m — współczynniki q; podłoga szumu E12) jest **oszacowaniem kondycji, NIE certyfikowanym przedziałem błędu** (przy małym |q′|, skupionych pierwiastkach i błędach samego DK niewystarczającym) — raportowane osobno od residuum, domknięć (1.5d), kompletności i stabilności klasyfikacji. **Eskalacja precyzji:** wyłącznie gdy margines numeryczny zachodzi na decyzję (|V_f − próg| < Δ_num(V_f) + Δ_num realizacji wyznaczającej próg; przy remisie progowym — maksimum Δ_num realizacji o wartości progu; errata 11k), dokładnie jedna eskalacja (podwyższona precyzja DK + przeskalowane residuum), wynik wiążący niezależnie od etykiety; **eskalacja rozstrzyga jednoznaczność, nie kierunek — iterowanie do oczekiwanej kategorii zabronione.** Dodatki 11l: **(A2) Propagacja błędu na miarę i progi:** dla pierwiastka (także zespolonego) ||μ̂| − |μ|| ≤ |μ̂ − μ|, zatem błąd modułu Δρ_z ≤ Δ_num(μ̂); wobec ρ_AB wyznaczonego exact potokiem 1.3–1.6 (C5) ΔV_z = Δρ_z/ρ_AB.

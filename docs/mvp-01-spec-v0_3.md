**1.5 Asercje exact per realizacja (warstwa I — certyfikaty; fail-fast przed klasyfikacją, identyfikator realizacji w raporcie):**
- **(a) Rząd:** Bareiss z pełnym pivotowaniem na M := N_z − 256³⁸·I: rząd(M) = 22; certyfikat = lista pivotów (odtwarzalna).
- **(b) Prostota algebraiczna PF:** p_Nz(256³⁸) = 0 oraz (λ−256³⁸)² ∤ p_Nz (podzielenie syntetyczne BigInt, reszta ≠ 0). Uzasadnienie strukturalne (uwaga Asteriona 11j, przyjęta): R_z = N_z/256³⁸ jest nieujemną macierzą stochastyczną WIERSZOWO (nieujemność i sumy wierszy = 256³⁸ dokładnie, konstrukcyjnie z definicji S_A, S_B; „konwencja kolumnowa" §0 oznacza kolejność składania operatorów, nie stochastyczność kolumnową — errata 11k po ataku Claude'a), zatem potęgi R_z są ograniczone (||R_z^k||_∞ = 1), co wyklucza nietrywialny blok Jordana przy |λ| = 1; certyfikat liczbowy (b) wymagany mimo dowodu.
- **(c) ρ_z < 256³⁸ (certyfikat Schur–Cohn, exact, konwencja jawna):** q(μ) := p_Nz(256³⁸·μ)/256^(38·23) — wielomian moniczny stopnia 23 o współczynnikach wymiernych dyadycznych a_m(R_z)/256^(38·(23−m)) (errata 11k po ataku Claude'a: NIE całkowitych — implementacja zakładająca całkowitość ucina dzielenia i unieważnia certyfikat); q(1) = 0 (b); deflacja syntetyczna q(μ) = (μ−1)·r(μ), r moniczny stopnia 22, wymierny dyadyczny. Wszystkie operacje rekurencji na ułamkach (licznik/mianownik BigInt). Rekurencja Schura: P_22 := r; dla k = 22, …, 1: γ_k := P_k(0) (wyraz wolny); warunek certyfikatu: |γ_k| < 1 ∀k; redukcja P_{k−1}(z) := [P_k(z) − γ_k·P_k*(z)] / (z·(1 − γ_k²)), gdzie P_k*(z) = z^k·P_k(1/z); wszystkie operacje exact na ułamkach (licznik/mianownik BigInt); stopień 0 zamyka rekurencję. Tw. Schur–Cohna: r stabilny wewnętrznie (wszystkie pierwiastki |μ| < 1) ⇔ warunek spełniony ⇔ ρ_z < 256³⁸. Dowolne |γ_k| ≥ 1 ⇒ asercja fail (1.7).
- **(d) Domknięcia exact:** tr(N_z^k) z potęg macierzowych BigInt, k = 1, …, 4; zgodność z p_Nz (tożsamości Newtona); niezgodność ⇒ fail. Kontrola anty-cyrkularna (lekcja E11; errata 11k po ataku Claude'a): dla pre-registrowanych stałych λ₀ ∈ {256³⁸, 256³⁸+1, 2·256³⁸} porównanie p_Nz(λ₀) z det(λ₀·I − N_z) policowanym Bareissem — niezależna droga rachunkowa od Leverriera; niezgodność ⇒ fail.
- **(e) Degeneracja:** p_Nz(i,j) = p_Nz(j,i) współczynnik po współczynniku, wykonywana dla par i < j; niezgodność ⇒ fail.
